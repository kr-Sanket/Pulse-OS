# PulseOS

**A Patient-Centric Healthcare Interoperability Platform** — Universal Health Identity,
patient-controlled granular consent, a tamper-evident audit trail designed for blockchain
anchoring, and AI-powered medical intelligence. Final-year project, 2026, team of 3. Built to
production standards with a research publication goal.

*One Patient. One Identity. One Health History. Accessible Anywhere.*

> All patient data in this project is synthetic. PulseOS is a research prototype, not a medical
> device, and provides no medical advice.

## Quickstart

**Prerequisites:** Docker Desktop, Python ≥ 3.12, Node ≥ 20 with pnpm
(`corepack enable` gives you pnpm), `make`.

```bash
# 1. Clone and enter
git clone <repo-url> pulse-os && cd pulse-os

# 2. Create your .env (safe local defaults; no edits needed for local dev)
make env

# 3. Start infrastructure: PostgreSQL (pgvector image; extension unused), Redis, MinIO (+ bucket bootstrap)
#    PostgreSQL is published on host port 5433 (it listens on 5432 inside the container).
make up

# 4. Install dependencies (backend venv + web workspace)
make install

# 5. Run the backend  →  http://localhost:8000  (health: /health, docs: /docs)
make dev-api

# 6. Run a portal (separate terminal)
make dev-patient    # http://localhost:5173
make dev-doctor     # http://localhost:5174
make dev-hospital   # http://localhost:5175
```

**Quality checks** (same as CI): `make lint`, `make typecheck`, `make test` — or all at once,
`make ci`. Auto-format with `make format`. Stop infrastructure with `make down` (data persists
in named volumes). There is no end-to-end (Playwright) suite.

**MinIO console:** http://localhost:9001 (credentials in your `.env`).

**Database, auth and AI:** apply migrations and seed before first use; every authenticated call
needs Firebase credentials; run a local Ollama for the AI endpoints (or set
`PULSEOS_AI_PROVIDER=fake`) — see [`docs/DEVELOPMENT_GUIDE.md`](docs/DEVELOPMENT_GUIDE.md).

## Status

Detailed, dated status and validation evidence live in [`.claude/ROADMAP.md`](.claude/ROADMAP.md);
this is a summary as of 2026-10-14 (`72b55e2`, pushed to `origin/main`).

- **Complete:** M0 foundation, M2 backend core, M3 consent domain (gate criteria met in code).
- **Substantially done (M4):** patient, doctor and hospital portals on real APIs, including the
  full consent journey; **in-app notifications** for access requested / approved / rejected /
  revoked (ADR-031); automatic polling refresh of consent and permission screens. Still open:
  QR identity, SYSTEM_ADMIN provisioning (self-registered hospitals cannot be verified), hospital
  bulk upload; the patient portal answers all requested categories at once.
- **Partially built (M5 AI):** Synthea FHIR R4 **import** (CLI) with ingestion into AI chunks,
  consent-scoped **lexical** retrieval (no embeddings), a clinician AI assistant and a patient
  Health Copilot generated by a **local Ollama model (Qwen3:8B)**. OCR, summaries, timeline and
  report explainer are not built; there is no FHIR export.
- **Audit integrity — local only (M6.1–M6.3):** every consent and access event is hashed
  (versioned digests, Keccak-256 for new events); events can be sealed into Merkle batches with a
  32-byte commitment and reconciled against the database. This runs in tests only — no scheduler,
  CLI or UI yet — and the anchor adapter is a network-free simulation.
- **Not built:** any blockchain submission. **Polygon anchoring is a design goal, not an
  implemented feature** (no contract, adapter, wallet or receipts; M6.4 is not authorized). M7
  hardening and deployment have not started.

The backend exposes 38 operations under `/api/v1` plus `/health` and `/ready` (the generated
OpenAPI is authoritative). Latest local run (2026-10-15, `72b55e2` plus uncommitted changes):
backend **1165 passed, 25 skipped** without the opt-in PostgreSQL tests and **1190 passed** with
them (disposable PostgreSQL 16); ruff and mypy clean; web **550 passed**, format/lint/typecheck
clean. Local runs only — GitHub Actions has not run on these uncommitted changes. See
[`.claude/SESSION.md`](.claude/SESSION.md) for the current handoff and
[`.claude/TODO.md`](.claude/TODO.md) for remaining work.

## Stack (summary)

FastAPI modular monolith · PostgreSQL · Redis (rate limits, arq) · S3/MinIO · Firebase Auth ·
React 19 + TypeScript monorepo (3 portals) · local Ollama (Qwen3:8B) with lexical retrieval ·
Keccak-256 / Merkle audit batches (public-chain anchoring planned, not built) · Docker Compose ·
GitHub Actions. Flutter patient app not started.
